# Letter Flower 💜

Un pequeño regalo digital hecho con amor, compuesto por una carta romántica y una flor artística inspirada en el espacio.

### ¿Qué contiene?
- Una carta personalizada con un diseño celestial.
- Una flor creada con arte puntillista y miles de partículas.
- Un fondo cósmico con estrellas y efectos luminosos.
- Un listón rosa personalizado con las iniciales J y V.

### ¿Cómo funciona?
Al abrir la página aparece la carta. Al presionar el botón, se revela la flor, que florece gradualmente mientras se forma su listón.

Una vez completamente abierta, permanece florecida, con pequeños movimientos y efectos de luz. También se puede repetir la animación cuando se desee.
